# Умный подбор event-подрядчиков

Проект помогает подобрать до трёх подрядчиков для мероприятия по городу, дате, категории, формату, бюджету, языкам и длительности. Сейчас в репозитории есть backend и HTTP API. Пользовательского веб-интерфейса пока нет; запросы можно отправлять через страницу FastAPI.

## Что делает backend

- фильтрует подрядчиков по заданным условиям и календарю занятости;
- возвращает до трёх карточек в предсказуемом порядке;
- объясняет выбор с помощью `LLMExplainer` для подходящих карточек;
- использует локальные фактические сообщения, если API недоступен или ключ не задан;
- возвращает понятное сообщение, если категория не найдена или никто не прошёл фильтры.

Подбор кандидатов выполняет backend. LLM формулирует объяснение и не выбирает подрядчиков.

## Запуск API на macOS или Linux

Из корневой папки проекта выполните:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
```

Чтобы включить OpenAI, откройте `.env` и укажите свой ключ в `OPENAI_API_KEY`. Не добавляйте настоящий ключ в GitHub. Затем запустите сервер:

```bash
.venv/bin/python -m uvicorn api:app --reload --host 127.0.0.1 --port 8000
```

Откройте [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs). Выберите `POST /recommendations`, нажмите **Try it out** и отправьте, например, такой запрос:

```json
{
  "city": "Алматы",
  "date": "2026-10-10",
  "event_format": "корпоратив",
  "category": "Ведущий",
  "budget_kzt": 1500000,
  "languages": [],
  "duration_hours": null
}
```

Другие команды запуска и устройство API описаны в [BACKEND_README.md](BACKEND_README.md). Настройки провайдера находятся в `.env.example`.

## Основные файлы

| Файл | Назначение |
|---|---|
| `api.py` | HTTP API: `/health`, `/options` и `/recommendations` |
| `src/filter_engine.py` | проверка условий и отбор подрядчиков |
| `src/recommendation_service.py` | соединяет фильтрацию с объяснениями |
| `src/llm_explainer.py` | объяснения через OpenAI или NVIDIA и локальный fallback |
| `data/` | каталог подрядчиков |
| `main.py`, `demo.py` | запуск поиска и демонстрационных сценариев из терминала |
| `docs/TEAM_INTEGRATION.md` | контракт для подключения интерфейса |

## Данные и ограничения

Каталог содержит 66 профилей и календарь на период с 23 сентября по 31 декабря 2026 года. Цена в профиле — начальная, а не подтверждённая итоговая стоимость. Часть цен и городов восстановлена; соответствующие профили помечены флагами. Бронирование и связь с подрядчиками не выполняются.

Полный веб-интерфейс для пользователя ещё не добавлен. `/docs` — страница для проверки API, а не готовое приложение для заказчиков.
