# Проверка бэкенда

Проверено 23 сентября 2026 года в Linux, Python 3.12.14.

- 81 автоматический тест прошёл, ошибок нет (включая два теста совместимости с уже существующим модулем участника 2).
- Внутри одного теста проверены 200 воспроизводимых запросов по независимому прямому отбору.
- Исходный CSV и поставляемый JSONL дают одинаковые профили: 66 записей, 13 synthetic=true, 8 city_imputed=true, 18 price_imputed=true, 9 max_hours=null.
- Реальный сервер Uvicorn стартовал на localhost; GET /health и все 6 POST /recommendations проверены через HTTP.
- Консольная демонстрация работает на обычном Python без сторонних пакетов.
- Изменение порядка входных записей не меняет результат.

## Скорость

600 вызовов ядра (6 запросов по 100 повторов), данные уже загружены:

- медиана: 0.092 мс;
- максимум в этой серии: 2.136 мс.

Максимум в отдельной серии из 6 локальных HTTP-вызовов через TestClient: 5.269 мс. Этот HTTP-замер сделан до уточнения выбора цитаты в резервном объяснении. Финальная версия логики проверена повторно автоматическими тестами.

Это измерения в среде разработки, а не гарантия для любого компьютера. Загрузка Python, первый импорт, внешняя сеть, OpenAI/NVIDIA и Streamlit не включены в замер ядра. Вызовы LLM не реализованы в этой части и не тестировались.

## Зависимости и предупреждения

Тесты выполнены с версиями из requirements.txt и requirements-dev.txt. Полный снимок проверенного окружения: requirements-lock.txt. Команда полного воспроизведения: `python -m pip install -r requirements-lock.txt`, затем `python -m pytest -q`.

Среда тестов выводит одно предупреждение Starlette о будущем переходе TestClient с httpx на httpx2. Оно не является ошибкой и не относится к фильтрам или рабочему HTTP API. Текущая комбинация зависимостей проверена.

## Границы проверки

- Windows-команды подготовлены, но непосредственно в Windows не запускались.
- Google Docs по ссылке недоступен; реализация опирается на приложенный PDF и CSV.
- Ключи API не добавлялись; существующий модуль участника 2 проверен в локальном режиме без внешнего вызова.
- Семантическая достоверность свободного текста LLM не проверяется функцией apply_explanations: она проверяет форму ответа и набор ID.
